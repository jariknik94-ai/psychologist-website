# 🌸 Сайт психолога Анастасии Никуличевой

Персональный сайт психолога: онлайн-консультации, очные групповые встречи, статьи и контакты для записи.

**Стек:** Next.js (App Router), React, TypeScript, SCSS Modules. Размещение — Vercel.

## 🚀 Запуск и проверка

Требуется Node.js. В папке проекта выполните:

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npx tsc --noEmit
npm run build
npm run start
```

`npm run start` запускает production-сборку после `npm run build`.

## 🧭 Страницы

| Адрес | Содержимое |
| --- | --- |
| `/` | Главная |
| `/about` | О психологе |
| `/services` | Форматы консультаций |
| `/services/group` | Групповые встречи |
| `/articles` | Список статей |
| `/articles/[slug]` | Страница статьи |
| `/contacts` | Контакты |

## 📁 Где что менять

- `src/app/` — страницы, метаданные и глобальные стили (`globals.scss`).
- `src/components/` — компоненты страниц, общие блоки и элементы интерфейса; стили компонентов хранятся рядом в `*.module.scss`.
- `src/styles/` — общие SCSS-примеси для оформления страниц, бумажных карточек и акварельных кнопок.
- `src/data/site.ts` — сведения о специалисте, контакты и условия встреч.
- `src/data/articles.ts` — статьи; их типы описаны в `src/types/article.ts`.
- `src/data/config.ts` — адрес сайта. При подключении домена измените `siteUrl`.
- `public/images/` — фотографии, обложки, фоны и графика; `public/icons/` — иконки устройств.
- `src/app/fonts/` — локальные шрифты Manrope и Lora и их лицензии.

## 📝 Контент и статьи

Часть сведений и статей пока заполнена заглушками и требует согласования со специалистом.

Статья добавляется в массив `articles` с уникальным `slug`, который формирует адрес `/articles/[slug]`. Для черновика используйте `status: "draft"`, для готовой статьи — `status: "published"`.

**Черновики видны посетителям**, но содержат указание `noindex` и не включаются в карту сайта. После изменения данных выполните новую сборку.

## 🌐 Публикация
